# Paperclaw

AI vision paper crawler scaffold focused on collecting AI vision papers from arXiv and OpenReview.

## Running the bootstrap CLI

Create a virtual environment for Python 3.12+, install the project, then run the entry point:

```
python run_once.py
```

This script currently only exits immediately with `0`.

## Running the tests

From the repository root:

```
pytest tests/test_run_once.py -q
```
