# Paperclaw 使用说明

## 1. 项目简介

`Paperclaw` 是一个面向 AI 视觉方向论文的抓取脚本，当前 MVP 支持：

- 从 `arXiv` 抓取论文
- 从 `OpenReview` 抓取论文
- 将论文写入本地 `SQLite`
- 通过飞书机器人发送新增论文通知
- 使用 `cron` 做定时执行

当前 `CVF` 仅保留了占位接口，尚未实现真实抓取逻辑。

## 2. 运行环境

- Python `3.12` 或更高版本
- Linux 服务器或本地 Linux/macOS 环境
- 可选：飞书机器人 webhook

## 3. 安装步骤

在项目根目录执行：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -U pip
python -m pip install -e .[dev]
```

如果你使用的是 Conda 或其他 Python 环境管理方式，也可以直接安装：

```bash
python -m pip install -e .[dev]
```

## 4. 配置说明

### 4.1 环境变量

先复制配置模板：

```bash
cp .env.example .env
```

当前支持的环境变量如下：

- `DATABASE_URL`
  - 数据库地址
  - 默认建议：`sqlite:///data/papers.db`
- `FEISHU_BOT_WEBHOOK`
  - 飞书机器人 webhook
  - 为空时不会发送飞书通知
- `LOG_LEVEL`
  - 日志级别，如 `INFO`、`WARNING`、`ERROR`
- `TIMEZONE`
  - 时区配置，当前默认值为 `Asia/Shanghai`
- `MAX_NOTIFY_ITEMS`
  - 单次通知最多展示的论文数量

推荐配置示例：

```env
DATABASE_URL=sqlite:///data/papers.db
FEISHU_BOT_WEBHOOK=
LOG_LEVEL=INFO
TIMEZONE=Asia/Shanghai
MAX_NOTIFY_ITEMS=10
```

### 4.2 抓取源配置

抓取源配置文件位于：

```text
config/sources.yaml
```

当前默认示例：

```yaml
arxiv:
  enabled: true
  categories:
    - cs.CV
```

你也可以扩展为同时启用 `OpenReview`，例如：

```yaml
arxiv:
  enabled: true
  categories:
    - cs.CV
    - cs.AI
  lookback_days: 3

openreview:
  enabled: true
  venues:
    - CVPR
    - ICCV
  lookback_days: 7
```

字段说明：

- `enabled`
  - 是否启用该来源
- `categories`
  - `arXiv` 分类过滤列表
- `venues`
  - `OpenReview` 的会议前缀过滤，例如 `CVPR`
- `lookback_days`
  - 回看最近多少天的数据

## 5. 手动运行

在项目根目录执行：

```bash
python run_once.py
```

程序会完成以下流程：

1. 读取 `.env`
2. 读取 `config/sources.yaml`
3. 初始化日志
4. 创建启用的抓取源
5. 执行抓取、标准化、入库
6. 如配置了飞书 webhook，则发送通知

成功时进程退出码为 `0`；发生启动或运行级错误时退出码为非 `0`。

## 6. 数据存储

当前默认数据库为 `SQLite`。

如果你使用默认配置：

```env
DATABASE_URL=sqlite:///data/papers.db
```

那么首次运行后会生成：

```text
data/papers.db
```

数据库中包含的核心表有：

- `papers`
- `paper_versions`
- `crawl_runs`
- `notifications`

## 7. 飞书通知

如果你希望启用飞书通知，需要在 `.env` 中配置：

```env
FEISHU_BOT_WEBHOOK=https://open.feishu.cn/open-apis/bot/v2/hook/xxxx
```

当前通知方式为纯文本消息，内容会包含：

- 汇总标题
- 新论文标题
- 论文链接

如果不配置 `FEISHU_BOT_WEBHOOK`，程序仍可正常抓取和入库，只是不发送通知。

## 8. 定时执行

项目已提供 cron 示例文件：

```text
scripts/setup_cron.example
```

其内容为：

```bash
0 8 * * * cd /root/workspace/paperclaw && /usr/bin/python3 run_once.py >> logs/cron.log 2>&1
```

你可以直接安装：

```bash
crontab scripts/setup_cron.example
```

也可以手动编辑：

```bash
crontab -e
```

建议上线前确认：

- Python 路径正确
- 项目路径正确
- 运行用户对项目目录有读写权限
- `data/`、`logs/` 目录可写

## 11. 常见问题

### 11.1 为什么运行后没有飞书消息？

先检查：

- `.env` 中是否配置了 `FEISHU_BOT_WEBHOOK`
- 本次运行是否真的抓取到了“新增论文”
- `MAX_NOTIFY_ITEMS` 是否设置过小

### 11.2 为什么数据库文件没有生成？

先检查：

- `DATABASE_URL` 是否正确
- 当前用户是否有写入目录权限
- 程序是否真的执行成功

### 11.3 不想访问真实远端，只想本地验证脚本能否启动怎么办？

可以临时把 `config/sources.yaml` 里的来源全部关闭：

```yaml
arxiv:
  enabled: false

openreview:
  enabled: false
```

此时程序仍能完成配置加载、数据库初始化和整体流程验证。
